# Additional batch — 13 November 2026

Five separate static website concepts are in this folder. Open index.html for the list; each business has its own folder and index.html. Shared styling is in styles.css.

All are independent unsolicited concepts, not official websites. Verify phone, hours, address, menu, prices, social links and services with each owner. No orders or reservations are enabled; enquiry opens WhatsApp and requires the user to send manually.

The repository root already has a Netlify static-site configuration. After importing the repository into a new Netlify project, these demos will be available under /prospects/2026-11-13/batch-2/. The current Netlify connector does not expose a deploy upload or Git-provider linking action, so no live URL is claimed.
