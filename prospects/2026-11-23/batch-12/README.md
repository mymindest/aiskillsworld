## Deploy each demo separately on Netlify
1. Open the import link supplied in the report.
2. Connect `mymindest/aiskillsworld`.
3. Set the base directory to `prospects/2026-11-23/batch-12/<business-folder>`.
4. Leave the build command blank.
5. Set the publish directory to `.`.
6. Deploy and verify the generated URL before sharing it.
