# AI Skills World — Gaya Restaurant Website Concepts (17 Nov 2026)

Five independent, unsolicited concept demos are included. Each folder contains index.html and prospect.json. The root index.html links to all five demos.

Each page is mobile-responsive and includes SEO metadata, noindex/nofollow, keyboard focus states, a skip link, Google Maps, click-to-call where a public phone is verified, and a client-side copy-enquiry action. No visitor data is stored. No WhatsApp link is shown without an independently verified WhatsApp number. No order, payment or reservation workflow is enabled.

All menu references are marked as public listing/review mentions, not owner-approved menus. Confirm all business details and obtain owner approval before publication.
