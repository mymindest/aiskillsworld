# AI Skills World — Gaya Restaurant Website Concepts (18 Nov 2026)

Five independent, unsolicited concept demos are included. Each folder contains `index.html` and `prospect.json`; root `index.html` links to all five.

## Demo behaviour
- Mobile-responsive static HTML/CSS/JS; no build step or external library.
- SEO title/description and Open Graph basics; `noindex,nofollow` keeps unsolicited previews out of search indexing.
- Skip link, semantic landmarks, visible keyboard focus, labelled fields and reduced-motion support.
- Google Maps search links for every prospect.
- Click-to-call only where a public phone was independently found.
- WhatsApp is not enabled without an owner-confirmed number.
- Enquiry composer copies text locally; it does not send or store data.
- No ordering, payments or bookings are enabled.
- Menu references are marked as public listing/review mentions, not owner-approved menus.
- Every page says it is an independent unsolicited concept, not an official site, and requires owner approval before publication.
