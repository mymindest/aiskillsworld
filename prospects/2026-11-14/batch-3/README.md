# AI Skills World — Gaya District Restaurant Website Concepts (14 Nov 2026)

Five independent, unsolicited, mobile-responsive website concept demos:
- cafe-raahi/
- bodhi-rooftop-restaurant/
- the-baudhik/
- thai-spice-restaurant/
- kalyan-restaurant/

The root `index.html` links to all demos. Each demo includes a public listing snapshot, SEO metadata, responsive layout, accessibility basics, Google Maps, call and WhatsApp enquiry links, and an enquiry form that opens WhatsApp with a prefilled message. The form does not send automatically or store data.

## Before launch
Get written owner approval. Confirm business identity, phone, WhatsApp, hours, address/entrance, menu, prices, photos, official social links and service workflows. No ordering or booking is enabled because no owner-confirmed workflow was verified. Do not add testimonials, awards, prices or claims without approval.

## Netlify
Static site; no build command; publish directory `.`. Import only this folder using:
