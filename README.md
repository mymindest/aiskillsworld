## Deploy to Netlify

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/mymindest/aiskillsworld)

After authorizing GitHub/Netlify, select the `main` branch, leave the build command blank, and set the publish directory to `.`. The root `netlify.toml` defines the publish directory.

Each restaurant concept will be available as a page under the same Netlify site:
- `/prakash-hotel.html`
- `/the-food-hub-cafe.html`
- `/green-cafe-restaurant.html`
- `/magadh-biryani-cafe.html`

`.netlify` is excluded in `.gitignore`; do not commit local Netlify state.
